# uru-paper-format digest

Formats a scientific manuscript for Revista Tecnocientífica URU (No. 26 norms) as one `.md` spec that mirrors the journal's structure, typography and citation rules.

## Always-on rules

- Interview first, in order: article type, language, cover page, abstract (ES/EN), keywords, body, figures/tables/equations, references. Propose the outline and wait for approval before the full spec.
- Article type sets structure and page limit: 20 pages, or 8 for nota técnica. Confirm the content fits the type by method and intent, not just subject matter.
- Typography: Times New Roman 12pt justified; title 16pt bold centered; captions 10pt; section names bold centered; subsections bold, left, Title Case.
- Double spacing, except resumen/abstract, agradecimientos and references (single).
- Cover: up to 6 authors; name as `Primer nombre, inicial del segundo, Primer apellido-Segundo apellido`; each with affiliation, city, country, email, ORCID.
- Resumen/abstract: ES and EN, 200 words max each, one paragraph. Keywords: 5 max each.
- First use of any acronym: full name then the sigla in parentheses, in title, abstract and body.
- Figures "Figura", tables "Tabla" (title above), equations numbered in parentheses; SI units throughout.
- Citations: bracketed numbers in order of first appearance. Long quotes (40+ words) block-indented 1.25 cm.
- Reference format depends on source type (book, chapter, article, standard, patent, thesis, report, catalog, app).
- Submission checklist: original and unpublished; copyright letter from all co-authors; citations and references match; bioethics statement if humans, animals, GMOs or hazardous agents are involved.

## Hard constraints

- Never start the manuscript spec before the interview is complete.
- Never invent content. Missing fields are marked `[FALTA: <campo>]`.
- Never apply the wrong reference template for a source type.
- Output is one `.md` file only: no .docx, PDF or styling code.
