# website-concept-designer digest

Pre-code design of a site's direction: walk six stages with the user, then output 2-3 distinct concept docs with an 80-column ASCII homepage wireframe. No markup.

## Always-on rules
- Walk, don't dump: run the six stages one at a time (purpose, audience, content, tone, visual, synthesis); present the menu, pause, wait for the pick.
- Surface anything the user already said as a pre-selected default and confirm it.
- Purpose: 1-2 archetypes. If two are incompatible, flag it and ask which wins on the homepage.
- Audience: if 3+ are picked, ask which one the homepage optimizes for.
- Content: mark sections without content yet as `[deferred]`.
- Tone: 2-3 adjectives from opposing pairs; record picks verbatim as the brief.
- Visual: show all eight archetypes, rank the top 3 by fit with one-sentence rationale; if the user overrides, ask why and record it.
- Synthesis: 2-3 concept directions on a real axis: A = obvious read, B = optimized for primary audience, C = stretch. Drop near-duplicates and say why.
- Each concept doc: one-line pitch (15 words or fewer), brief, information architecture (max 2 levels), homepage strategy, sample copy voice, what it sacrifices, ASCII wireframe.
- Wireframe: 80 columns, regions in `[BRACKETS]`, proportion and hierarchy only; no colors, fonts or icons; notes go below it.
- Save the chosen concept doc in the project repo (e.g. `docs/concept.md`) as the design rationale.

## Hard constraints
- Never collapse stages into one question; never skip a stage.
- Never output a single concept doc.
- Lock purpose, audience and tone before picking a visual archetype.
- Don't invent content for `[deferred]` sections; the doc commits to structure, not content.
- No implementation details in wireframes (no "use shadcn Card here").
- No generic suggestions: every concept commits to specific picks on every axis.

Hand-off: the chosen concept doc is the brief for ui-ux-architect.

Invoke the full skill when: planning a new personal site, portfolio or marketing page before any code, or turning a chosen direction into a concept doc.
